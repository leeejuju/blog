# What is Agent Harness

在2月的时候，OpenAI推出了 **Harness engineering: leveraging Codex in an agent-first world**

称当时他们迁移内部的产品的业务逻辑，测试，CI/CD, 记录，观测以及内部的工具化，未参考任何之前的文档，甚至Agent.md一套全是codex搞出来的，https://openai.com/index/harness-engineering/

但是整篇文章重点讲述了 harness 工程中影像，而未解释harness本身，通过什么组织架构或者方式实现了 All Written by codex

## Harness 的组成：Tool 注入、Middleware 链、Backend 绑定
